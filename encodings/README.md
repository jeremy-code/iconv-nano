# iconv-nano/encodings

Encodings were generated via [scripts/generate-encodings.ts](../scripts/generate-encodings.ts) by parsing the [indexes.json](https://github.com/whatwg/encoding/blob/main/indexes.json) file from the [whatwg/encoding](https://github.com/whatwg/encoding) GitHub repository.

The SHA-256 checksum for the `indexes.json` file that was used to create the encodings is located at [indexes.sha256](./indexes.sha256).

Some modifications were made to the original file based on the [WHATWG encoding spec on indexes](https://encoding.spec.whatwg.org/#indexes):

- [`gb18030-ranges.json`](./gb18030-ranges.json) was flattened for a more optimal data representation.
- There is no Shift_JIS index. The Shift_JIS encoder reuses [`jis0208.ts`](./jis0208.ts) and remaps the excluded pointers ([`../src/codecs/shift_jis.ts`](../src/codecs/shift_jis.ts)).
- Single-byte encodings ([`ibm866.json`](./ibm866.json), `iso-8859-*.json`, `koi8-*.json`, `windows-*.json`, [`x-mac-cyrillic.json`](./x-mac-cyrillic.json)) were preserved as-is, except that holes were replaced with -1.
- [iso-2022-jp-katakana.json](./iso-2022-jp-katakana.json) was preserved as-is.
- Additionally, some encodings are stored as a VLQ-encoded run-length payload (see `encodeVlqRunsPayload` in [`scripts/utils/vlqRuns.ts`](../scripts/utils/vlqRuns.ts), decoded at runtime by [`src/utils/vlqRuns.ts`](../src/utils/vlqRuns.ts)) to optimize performance and size. Currently applied to: [`big5.ts`](./big5.ts), [`euc-kr.ts`](./euc-kr.ts), [`gb18030.ts`](./gb18030.ts), [`jis0208.ts`](./jis0208.ts), [`jis0212.ts`](./jis0212.ts).

JSON encoding indices are imported by `iconv-nano` in the development code but are compiled into minified JavaScript files during build time.

<details>
  <summary>The index values that differ between JIS0208 and Shift JIS. They correspond to pointers 0x2050 (8272) to 0x21c7 (8647), which correspond to the pointers excluded in the [specification](https://encoding.spec.whatwg.org/#indexes).</summary>

To generate values unique to JIS0208 compared to Shift JIS, run the following script.

```ts
import indexes from "https://raw.githubusercontent.com/whatwg/encoding/refs/heads/main/indexes.json" with { type: "json" };

const jis0208EncodingIndex: (number | null)[] = indexes.jis0208;

const uniqueJis0208Characters = Object.fromEntries(
  jis0208EncodingIndex
    .map((codePoint, index) => [codePoint, index] as const)
    .slice(8272, 8836)
    .flatMap(([codePoint, index]) =>
      codePoint === null
        ? []
        : [
            [
              "0x" + index.toString(16).padStart(4),
              [codePoint, String.fromCodePoint(codePoint)],
            ],
          ],
    ),
);

console.log(uniqueJis0208Characters);
```
